# Conjecture de Hodge

## Cible

Établir que toute classe rationnelle de type `(p,p)` sur une variété projective lisse complexe est combinaison rationnelle de classes de cycles algébriques.

## Verrous suivis

- construction effective de cycles ;
- monodromie et groupes de Mumford–Tate ;
- dégénérescence et relèvement ;
- obstructions d'Abel–Jacobi et fonctions normales.

## Moteurs expérimentaux

Calcul de périodes, algèbre linéaire exacte, géométrie algorithmique et ponts vers Sage, OSCAR ou Macaulay2.
