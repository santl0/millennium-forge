# Hypothèse de Riemann

## Cible

Montrer que tous les zéros non triviaux de la fonction zêta de Riemann ont partie réelle `1/2`, ou produire un contre-exemple rigoureux.

## Verrous suivis

- critères de positivité et espaces complets de tests ;
- densité versus contrôle de chaque zéro ;
- flot de de Bruijn–Newman ;
- programmes spectraux avec identité exacte.

## Moteurs expérimentaux

Arithmétique d'intervalles, formes de Weil tronquées, calcul symbolique et modèles adverses contenant des exceptions rares.
