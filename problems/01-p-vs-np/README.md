# P versus NP

## Cible

Déterminer si les classes `P` et `NP` coïncident dans un modèle uniforme précis. Toute borne dans un modèle restreint conserve explicitement ce périmètre.

## Verrous suivis

- bornes inférieures de circuits ;
- relativisation, Natural Proofs et algébrisation ;
- méthodes algorithme-vers-borne ;
- complexité des preuves et métacomplexité.

## Moteurs expérimentaux

SAT/SMT, énumération de petits circuits, recherche de contre-exemples et formalisation de modèles de calcul.
