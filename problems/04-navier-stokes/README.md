# Navier–Stokes incompressible 3D

## Cible

Établir la régularité globale pour les données admissibles de l'énoncé Clay ou construire un blow-up admissible en temps fini.

## Verrous suivis

- supercriticité de l'énergie ;
- critères critiques de prolongement ;
- compacité–rigidité et solutions anciennes ;
- cascades, vorticité et profils singuliers.

## Moteurs expérimentaux

Recherche de profils, analyse spectrale, PINN comme outil de découverte, calcul d'intervalles et champs divergence-free adverses.
