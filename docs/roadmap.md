# Feuille de route

## Phase 0 — socle reproductible

- dépôt public et gouvernance ;
- schéma des affirmations ;
- six cellules scientifiques ;
- protocoles d'agents ;
- validation CI.

## Phase 1 — deux pilotes

- Riemann : graphe d'audit d'un résultat de frontière ;
- Navier–Stokes : expérience reproductible et analyse de raccord au cadre Clay.

## Phase 2 — preuve et contradiction

- génération automatique du graphe des dépendances ;
- files de tâches pour reproduction et contradiction ;
- premiers noyaux Lean ;
- tableau de bord statique dérivé de Git.

## Phase 3 — laboratoire continu

- veille bibliographique ;
- ordonnanceur persistant ;
- budgets de calcul ;
- réplications indépendantes ;
- publication de checkpoints versionnés.

## Phase 4 — calcul collaboratif

- paquets de calcul vérifiables ;
- résultats adressés par contenu ;
- réplication distribuée ;
- attribution publique des contributions humaines et IA.
